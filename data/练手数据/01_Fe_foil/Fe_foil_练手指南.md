# Fe 箔三条谱 · 练手操作卡

目录：`练手数据/01_Fe_foil/`
目标：用三条真实谱把「校准 → 对齐 → 归一化 → 扣背景 → 傅里叶变换 → 第一壳层拟合」整条链路走一遍，最后拿到 S02 和三个温度的 σ²。

---

## 一、源文件是什么

| 项 | 内容 |
|---|---|
| 文件 | `fe.060`、`fe.150`、`fe.300`（各约 22 KB） |
| 来源 | NSLS（美国布鲁克海文）**X-11A** 线站，环能 2.58 GeV，2002-10-03/04 采集 |
| 是什么 | 同一片 Fe 箔，分别在 **60 K / 150 K / 300 K** 下测的透射谱 |
| 格式 | **XDAC V1.2**：前 15 行是文件头，一条破折线，然后是 3 列数据 |
| 列 | `Energy(eV)` `I0` `It` —— 透射模式，吸收系数要自己算：**μ = ln(I0/It)** |
| 点数 | 511 点，6912 – 8963 eV |
| 边跃 | ln(I0/It) 约 **2.9**，不是 1。箔比较厚，正常，别以为错 |

文件头里有几个要留意的字段：

```
XDAC V1.2 Datafile V1
"fe.060" created on 10/3/02 at 10:20:36 PM on X-11A
Ring energy= 2.58 GeV
E0= 7112.00                     ← 标称值。数据实际是偏的，别信它
NUM_REGIONS= 3
SRB= -200 -20 20 22k            ← 分 3 段扫
SRSS= 5 0.5 0.05k               ← 边前 5 eV 步长、边区 0.5 eV、EXAFS 区 0.05 Å⁻¹
SPP= 2 2 2
Offsets= 9925.80 9914.40
Gains= 7.00 7.00
Iron foil, I0: 50%N2, It:N2     ← 只有这一行区分三个温度
```

**关键**：这组数据当年就是**故意把单色器调偏**的，专门用来教「校准」和「对齐」。所以第一步看到 E0 落在 7105–7106 附近是设计好的，不是数据坏了。

**先做一件事**：Demeter/Athena 对非英文字符路径有老毛病（安装路径和数据路径都不能有中文）。把 `01_Fe_foil` 整个复制到纯英文路径再开工，例如：

```
C:\EXAFS\fe_foil\
```

## 二、操作步骤（Athena）

> 每一步后面跟一个「判据」，做到判据才算过，别一口气点到底。

**第 1 步 · 导入 fe.060**
`File → Import data` → 选 `fe.060`。
列映射：Energy = 第 1 列，Numerator = 第 2 列（I0），Denominator = 第 3 列（It），勾选 `ln`（Natural log）。
> 判据：曲线出现一条边，`Data type` 显示 μ(E)（不是 xanes）。

**第 2 步 · 能量校准**
`Calibrate` 面板 → 勾 `derivative` → 点 `Select a point` → 在**一阶导数的第一个峰**上双击 → 输入 `7112` → 点 `Calibrate`。
> 判据：`Energy shift` 显示 **约 +6 ~ +7 eV**，E0 变成 7112.0。

**第 3 步 · 导入另外两条**
同样映射导入 `fe.150`、`fe.300`。
> 判据：三条谱都能显示，各自 Data type 为 μ(E)。

**第 4 步 · 对齐（最容易做错的一步）**
选中 `fe.150` → `Align` → 参考选 `fe.060` → 只做能量 shift。**然后手工把 fe.150 的 E0 也改成 7112**（`Align` 不会动 E0）。
`fe.300` 同样处理。
> 判据：三条谱在 k 空间（k²χ(k)）也重合。如果只在 E 空间重合、k 空间散开，就是 E0 没统一。

**第 5 步 · 归一化**
`Normalization`：pre-edge 两点取 E0−150 与 E0−30；post-edge 两点取 E0+150 与 E0+700；`Normalization order = 2`（边后略弯就用 2，直就用 1）。三条都做。
> 判据：边前贴在 0 上，边后振荡围绕 1；三条的边跃都在 2.8–3.0，彼此差 <1%。

**第 6 步 · 扣背景**
`Background removal`：**Rbkg = 1.0**；spline 区间从 E0 到 Emax；k-weight 分别设 1、2、3 各看一遍。
> 判据：k²χ(k) 在 k = 2–15 没有系统性上翘或下沉；|FT| 在 R < 1 Å 没有大鼓包。

**第 7 步 · 傅里叶变换**
Forward FT 参数：`kmin = 2.5`、`kmax = 12`（数据好可以给到 15）、`dk = 0.05`、窗 `Hanning`、R 范围 `0–6 Å`。
> 判据：第一壳层峰在 **R ≈ 2.2 Å**（未做相位校正，真实 Fe−Fe 是 2.48 Å）。

**第 8 步 · 建理论路径**
Athena 的 `Feff` 模块（或 Artemis 里的 Feff calculations）→ `Run Atoms`（Fe，bcc，a = 2.866 Å）→ `Run Feff` → 取 **Fe−Fe 2.48 Å 的第一壳层单散射**路径拖进路径列表。

**第 9 步 · 拟合 Fe 箔求 S02**
Fe 箔结构已知，**固定 N = 8**（bcc 第一壳层），拟合 `S02`、`R`、`σ²`、`ΔE0`；R 窗口 `1.8–3.0 Å`。
> 判据：S02 落在 **0.75–0.90**，R 落在 **2.46–2.50**，R-factor < 0.02。这个 S02 是同批次数据的公用值，后面样品直接固定用它。

**第 10 步 · 拟合另两个温度**
把 S02 设为 set（固定），分别拟合 150 K 与 300 K，只放 R、σ²、ΔE0。
> 判据：σ² 随温度单调增大。

**第 11 步 · 导出**
`File → Export` 把归一化 μ(E)、k²χ(k)、χ(R) 各导一份 CSV。
> Athena 出的图不适合直接上 PPT/论文。终图回 Origin 重绘（此时按你的字体配色规范：中文微软雅黑、数字 Times New Roman，暖色渐变）。

## 三、自查表（做完逐条对）

| 检查点 | 期望值 | 出问题说明什么 |
|---|---|---|
| 校准前 E0 | 7105–7106 | 若在 7112 附近，说明数据没被调偏或读错列 |
| Energy shift | +6 ~ +7 eV | 差太多就是选错了一阶导峰 |
| 校准后 E0 | 7112.0 | — |
| 边跃 | 2.8–3.0，三条一致 | 差很多说明某条没归一化好 |
| 可用 kmax | ≥ 15 Å⁻¹（这组能到 22） | 高 k 噪声大就在 12–14 截断 |
| \|FT\| 第一峰位置 | R ≈ 2.2 Å | 跑到 1.5 附近是背景没扣干净 |
| 峰高趋势 | 60 K > 150 K > 300 K | 反了就说明标签/温度搞混 |
| S02 | 0.75–0.90 | 落到 0.5 或 1.2 说明 N 设错或背景不对 |
| R(Fe−Fe) | 2.46–2.50 Å | — |
| σ² | 约 0.004–0.010 Å²，随 T 增大 | 超 0.02 说明模型或数据有问题 |
| R-factor | < 0.02 | > 0.05 说明拟合区间或路径不对 |

## 五、五个必踩的坑

1. **路径带中文** → Athena 打不开或导入乱码。先复制到 `C:\EXAFS\`。
2. **信了文件头里的 E0=7112** → 不做校准，后面 k 空间全歪。
3. **Align 之后忘了改 E0** → E 空间看着重合，k 空间散开，白干。
4. **把三条谱 merge 了** → 这是三个不同温度，不能合。merge 只用于同一样品的重复扫描。
5. **看到边跃 2.9 以为错** → 箔厚，正常。
